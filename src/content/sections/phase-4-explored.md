This was a deliberately narrow POC. Rather than building on the full Harbour and Crane infrastructure from Phase 3, the scope was kept minimal: GCP as the hosting environment and the ESco Myriad API as the integration point.

The implementation drew on two complementary threads:

- **The ESco Myriad API and GCP**, used to handle the promo code creation logic and serve the client portal.
- **Agentic AI capabilities**: the AMI model and work being developed by Ed were incorporated so that the client portal interaction could be AI-assisted, enabling clients to log in and create promo codes through a more intelligent, guided interface rather than a traditional form.

The goal was a working demo of end-to-end promo code creation: a client logs into the portal, goes through an AI-assisted flow, and a promo code is created in the system.
